# MiniProject 3 — Validation Reflection (Draft)

Reviewing the two validation logs showed that disagreements were concentrated in fields that require interpretation rather than simple transcription. The clearest example was `HasRecovered`: labels such as “Partially” and “Barely” do not fit the Coding Guide’s binary Yes/No categories, so the decision must be tied to whether activity resumed after a qualifying inactivity gap. The activity-pattern disagreements also showed that short-term fluctuation can coexist with a clear long-term decline; commit counts across the full timeline are important when choosing one category.

The evidence-based proposals in the combined log and disagreement-resolution CSV are provisional. They are not a substitute for discussing the differences with Tristan. In that discussion, we should check the disputed rows against the Coding Guide, agree on how to normalize nonstandard labels and missing author values, and record the agreed result without rewriting the original pre-discussion agreement status.

A key limitation is evidence coverage. The project-gap summaries help explain what happened after long pauses, but they do not necessarily prove the `RecentThemes` labels, which require inspection of each project’s ten most recent commits. Another issue is inconsistent representation: some rows use text such as “Not reported in source project statistics” where a missing author value would be clearer, and theme pairs use different separators. These should be normalized carefully without inventing data.

If repeating the validation, I would first apply the field definitions mechanically (especially the three-month recovery threshold and six-month current-status cutoff), then independently inspect the specific commits supporting borderline cases, and finally compare the two codings before meeting. This would make the disagreements easier to resolve and improve reproducibility. This draft should be updated after the actual partner discussion to describe what we agreed on and any remaining unresolved cases.
